# Política de seguridad

## Información sensible

Este proyecto puede procesar datos comerciales y de salud. Nunca publique en GitHub nombres, cédulas, historias clínicas, fotografías de expedientes, facturas, contratos, datos bancarios, respaldos, contraseñas, tokens o claves de API.

## Reporte de vulnerabilidades

No abra una incidencia pública con información sensible. Comuníquese directamente con la administración de VOLIA S.A.S. e incluya únicamente una descripción técnica sin datos reales.

## Alcance de protección

El PIN local reduce accesos casuales, pero no cifra la base local. Las computadoras deben usar contraseña de inicio, cifrado de disco, actualizaciones de seguridad y cuentas separadas.
